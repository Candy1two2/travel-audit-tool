# 🚗 自驾车差旅报销轨迹核查工具

一个纯前端工具，用于核查公司员工自驾车差旅报销的合理性。通过上传包含 GPS 轨迹的表格文件，在高德地图上可视化展示车辆行驶路线，支持与必经工作地点进行比对。

## ✨ 功能特性

- 📁 **文件上传** — 支持拖拽上传 Excel (.xlsx/.xls) 和 CSV 文件
- 🔧 **智能列映射** — 自动检测时间、经度、纬度列，也可手动选择
- 🗺️ **地图轨迹** — 基于高德地图，按日期用不同颜色绘制车辆行驶路线
- 📅 **日期切片器** — 按日期筛选轨迹，支持全选/反选
- ⭐ **工作地点标注** — 手动添加必经工作地点，以突出的星形标记显示在地图上
- 📋 **数据预览** — 上传后展示数据预览，方便核对
- 💾 **本地缓存** — API Key 和工作地点自动保存到浏览器本地

## 🚀 快速开始

### 1. 获取高德地图 API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册/登录账号
3. 进入「应用管理 → 我的应用」→「创建新应用」
4. 添加 Key，服务平台选择「Web端(JS API)」
5. 复制生成的 Key

> ⚠️ **注意**：高德 JS API 2.0 为免费服务，个人开发者每日有免费额度，足够正常使用。

### 2. 启动工具

直接用浏览器打开 `index.html` 即可使用（推荐使用 Chrome 或 Edge）。

如果有本地服务器（如 VS Code Live Server），通过 HTTP 访问体验更佳：

```bash
# Python 3
python -m http.server 8080

# Node.js (需安装 http-server)
npx http-server -p 8080
```

然后浏览器打开 `http://localhost:8080`

### 3. 使用步骤

1. **配置 API Key**：在页面右上角输入高德 API Key，点击保存
2. **上传文件**：拖拽或点击上传包含 GPS 数据的 Excel/CSV 文件
3. **列映射**：确认或调整时间、经度、纬度对应的列，点击「应用并加载轨迹」
4. **查看轨迹**：地图上会显示车辆行驶轨迹，不同日期用不同颜色
5. **筛选日期**：使用左侧日期选择器筛选特定日期的轨迹
6. **标注工作地点**：输入工作地点名称和地址（或手动输入经纬度），点击添加

## 📊 数据文件格式要求

表格文件需包含以下三列信息：

| 列 | 说明 | 示例值 |
|----|------|--------|
| 时间 | 日期+时间，支持多种格式 | `2024-01-15 08:30:00` |
| 经度 | GPS 经度，数值 | `116.397428` |
| 纬度 | GPS 纬度，数值 | `39.909230` |

### 支持的时间格式

- `2024-01-15 08:30:00`
- `2024/01/15 08:30:00`
- `2024-01-15T08:30:00`
- `2024年1月15日 8:30:00`
- Excel 日期序列号
- `2024-01-15`（仅日期，时间默认为 00:00）

### 示例 CSV 文件

```csv
时间,经度,纬度
2024-01-15 08:30:00,116.397428,39.909230
2024-01-15 09:15:00,116.410528,39.915230
2024-01-15 10:00:00,116.435628,39.908730
2024-01-15 10:45:00,116.458128,39.912430
```

## 🛠️ 技术栈

- 原生 HTML / CSS / JavaScript（无框架依赖）
- [高德地图 JS API 2.0](https://lbs.amap.com/api/javascript-api-v2/summary)
- [SheetJS](https://sheetjs.com/) — Excel 文件解析
- [Papa Parse](https://www.papaparse.com/) — CSV 文件解析
